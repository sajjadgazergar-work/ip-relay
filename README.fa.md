# ip-relay — راهنمای فارسی

**یک کلید رایگان را به یک استخر کامل از کلید رایگان تبدیل کنید — به‌صورت خودکار.**

ip-relay بین اپ‌های هوش مصنوعی شما و سرویس‌دهنده API قرار می‌گیرد که سقف رایگان آن **بر اساس آدرس IP** محدود شده است. به جای اینکه بعد از چند ده درخواست به سقف برسید، ip-relay هر درخواست را از طریق یک استخر چرخان از پروکسی‌ها عبور می‌دهد — پس هر درخواست می‌تواند از یک IP تازه بیاید که سهمیه رایگان خودش را دارد.

> ⚠️ **لطفاً اول این را بخوانید**: این ابزار محدودیت‌هایی را دور می‌زند که سرویس‌دهنده برای هر IP تعیین کرده. قبل از استفاده، قوانین سرویس‌دهنده را چک کنید و از آن سوءاستفاده نکنید. مسئولیت استفاده با خود شماست.

## این مشکل چه چیزی را حل می‌کند؟

| بدون ip-relay | با ip-relay |
|---|---|
| اپ شما از یک IP به مدل `deepseek-v4-flash-free` وصل می‌شود | اپ شما از **ده‌ها IP مختلف** وصل می‌شود |
| بعد از N درخواست در روز: **خطای 429 — سهمیه تمام شد** | هر IP سهمیه جداگانه خودش را دارد |
| باید ۲۴ ساعت صبر کنید تا سقف ریست شود | چرخش IP به‌صورت خودکار هنگام خطای سهمیه انجام می‌شود |

## امکانات

- ✅ **بدون تنظیم خاص**: با پیکربندی پیش‌فرض علیه سرویس رایگان opencode کار می‌کند (فقط اجرا کنید)
- ✅ **چرخش خودکار IP** هنگام خطای سهمیه
- ✅ **سازگار با OpenAI**: جایگزین مستقیم برای هر کلاینت OpenAI، گیت‌وی یا تجمیع‌کننده
- ✅ **استریم**: پشتیبانی کامل SSE برای chat completions
- ✅ **داشبورد وب**: وضعیت، آمار زنده، لاگ زنده و تنظیمات — بدون نیاز به دانش فنی
- ✅ **ذخیره تنظیمات** بین ری‌استارت‌ها (از طریق داشبورد)
- ✅ **Docker و systemd**: نصب با یک دستور روی هر سرور

## شروع سریع (غیر فنی)

### یک دستور — نصب و به‌روزرسانی

```bash
curl -sL https://raw.githubusercontent.com/sajjadgazergar-work/ip-relay/main/install.sh | bash
```

همین! اسکریپت:
- روی `/opt/ip-relay` نصب می‌کند (نصب جدید) **یا** خودکار یک نصب موجود را به‌روزرسانی می‌کند
- یک venv پایتون می‌سازد، وابستگی‌ها را نصب می‌کند و سرویس systemd را راه می‌اندازد
- **هیچ‌وقت تنظیمات شما را پاک نمی‌کند** (`.env`، `settings.json`) — اول از کد بکاپ می‌گیرد
- با یک بررسی سلامت تمام می‌شود

**شخصی‌سازی:**
```bash
# نصب در مسیر دیگر
curl -sL ...install.sh | bash -s -- --dir /home/you/ip-relay
# اجرا بدون systemd (دستی)
curl -sL ...install.sh | bash -s -- --manual
# اجرا با Docker
curl -sL ...install.sh | bash -s -- --docker
```

سپس در مرورگر باز کنید: **http://localhost:8080** (یا IP سرور) — داشبورد را می‌بینید.

### ویندوز (PowerShell)

```powershell
# دانلود نصب‌کننده (توجه: در PowerShell دستور curl در واقع Invoke-WebRequest است، پس از irm استفاده کنید):
irm https://raw.githubusercontent.com/sajjadgazergar-work/ip-relay/main/install.ps1 -OutFile install.ps1

# اجرا (بدون نیاز به ادمین):
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

یا یک‌خطی:

```powershell
iex (irm https://raw.githubusercontent.com/sajjadgazergar-work/ip-relay/main/install.ps1)
```

اسکریپت در `%LOCALAPPDATA%\ip-relay` نصب می‌کند، venv می‌سازد، وابستگی‌ها را نصب می‌کند و یک فایل **`start-ip-relay.bat`** می‌سازد که با دابل‌کلیک اجرا می‌شود. پرچم‌ها: `-Dir D:\ip-relay`، `-Manual` (بدون لانچر)، `-Docker`.

> ⚠️ اگر دستور لینوکسی `curl -sL ...` را در PowerShell چسبانده‌اید، به همین دلیل خطا داد — PowerShell نام `curl` را به `Invoke-WebRequest` تغییر می‌دهد که پارامتر `-sL` ندارد. از فرم `irm` بالا استفاده کنید.

### Docker — دستی

```bash
docker run -d --name ip-relay -p 8080:8080 -e PORT=8080 ghcr.io/<you>/ip-relay
```

سپس در مرورگر باز کنید: **http://localhost:8080**

### از سورس (توسعه‌دهندگان)

```bash
git clone https://github.com/sajjadgazergar-work/ip-relay
cd ip-relay
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
uvicorn ip_relay:app --host 0.0.0.0 --port 8080
```

## استفاده از داشبورد

رابط وب در آدرس `/` این‌ها را نشان می‌دهد:

- **وضعیت** — آیا رله سالم است؟
- **استخر پروکسی** — چند IP خروجی آماده و فعال داریم؟
- **درخواست‌ها / چرخش‌ها** — شمارنده‌های زنده استفاده
- **تنظیمات** — تغییر آدرس API بالادست، کلید، نرخ تازه‌سازی پروکسی و… (بدون ویرایش فایل)
- **لاگ زنده** — رله الان چه می‌کند

اگر `RELAY_API_KEY` تنظیم شده باشد، داشبورد از شما رمز می‌خواهد.

## اتصال اپ هوش مصنوعی شما

هر کلاینتی که با OpenAI سازگار باشد را به سرور خودتان وصل کنید:

```
Base URL: http://<سرور-شما>:8080/v1
API key:  هر چیزی که به‌عنوان کلید رله تنظیم کردید (یا خالی)
```

مثال با curl:

```bash
curl http://localhost:8080/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer public' \
  -d '{"model":"deepseek-v4-flash-free","messages":[{"role":"user","content":"سلام"}]}'
```

سازگار با:
- **OpenAI SDK ها** (پایتون، نود و…) — فقط `base_url` را عوض کنید
- **9router و تجمیع‌کننده‌های مشابه** — به‌عنوان یک provider اضافه کنید
- **هر چیزی که با API اپن‌ای‌آی صحبت می‌کند**

## تنظیمات

همه تنظیمات از داشبورد قابل تغییرند، یا از طریق متغیرهای محیطی:

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `UPSTREAM_BASE_URL` | `https://opencode.ai/zen/v1` | API بالادست سازگار با OpenAI |
| `UPSTREAM_API_KEY` | `public` | کلیدی که بالادست فرستاده می‌شود |
| `RELAY_API_KEY` | *(خالی)* | اختیاری — محافظت از رله و داشبورد با کلید |
| `PROXY_REFRESH_SEC` | `600` | هر چند ثانیه یک‌بار استخر پروکسی تازه شود |
| `PROXY_TEST_CONCURRENCY` | `12` | چند پروکسی همزمان تست شوند |
| `PROXY_MAX_CANDIDATES` | `150` | حداکثر کاندیدا در هر تازه‌سازی |
| `DIRECT_LANE` | `1` | اجازه خروج مستقیم (IP خود سرور) |
| `PROBE_MODEL` | `deepseek-v4-flash-free` | مدلی که برای تست پروکسی‌ها استفاده می‌شود |
| `PORT` | `8080` | پورت گوش دادن |

## چطور کار می‌کند؟

```
اپ / گیت‌وی شما
      │  درخواست‌های سازگار با OpenAI
      ▼
  ip-relay ──▶ استخر پروکسی (چرخش IP خروجی)
      │            ▲
      │            └── خطای سهمیه (429) → علامت‌گذاری IP سوخته، بعدی
      ▼
  API بالادست (opencode.ai/zen/v1)
```

- رله **پروکسی‌های HTTP رایگان** را از لیست‌های عمومی می‌گیرد
- هر کدام را با یک **درخواست واقعی ۱-توکن** تست می‌کند (هم زنده بودن را ثابت می‌کند هم اینکه IP آن سوخته نیست)
- هنگام خطای سهمیه، IP سوخته را **کنار می‌گذارد** و لین بعدی را امتحان می‌کند — بدون وقفه
- IP واقعی سرور شما **هیچ‌وقت** به بالادست نمی‌رسد (مگر `DIRECT_LANE` را فعال کنید)
